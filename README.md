# Handy Synth (体験型Webシンセサイザー)

音楽の専門知識がない子どもたちでも、直感的に音を奏でる「身体的な楽しさ」を体感できることを目的に開発した、体験型Webアプリケーションです。学園祭（駒場祭）に出展し、多くの来場者に体験していただきました。

### 公開リンク
ブラウザとカメラがあれば、以下のURLからすぐに体験していただけます：
**[Handy Synth デモサイト](https://seeyoumayday.github.io/Handy-Synth/)**
*(※カメラのアクセス許可が必要です。画像認識はブラウザ上の ml5.js (Handpose) でローカルに処理されるため、サーバー等に映像データが送信されることはありません。)*
*(※初回起動時は機械学習モデルのロードに伴い、**準備が整うまで十数秒〜数十秒ほど時間がかかる場合があります**。また、ブラウザの音声再生ポリシー制限のため、**「Start Audio」ボタンを押さないと音声合成および手の検出ループは開始されません**。)*


## 1. 作成物の説明（目的・背景）
* **開発の背景**：従来の楽器や音楽アプリは、楽譜の読み方や操作手順などの「事前の知識」を求められることが多く、小さな子どもが直感的に楽しむにはハードルがありました。
* **目的**：説明書を一切必要とせず、自身の「身体の動き」がそのまま音になる直感的なUX（ユーザー体験）を提供し、純粋に音を操る楽しさを届ける。

## 2. 自身が担当した役割
* **担当工程**：企画・要件定義、UI/UXデザイン設計、フロントエンド実装、音響システム構築まで、すべての工程を完全個人で担当しました。

## 3. 直面した課題と解決方法

### 課題：操作の難易度と音色の表現力不足（UX・インタラクション設計の課題）
* **背景と課題**：
  開発初期は「指の開閉距離で音高を変え、手の横位置でピッチベンド、縦位置でフィルターのカットオフを変更する」という設計でした。しかし、テスト時に「指の開閉で狙った音高を正確に出すのは、身体のコントロール的に非常に難しい」という課題が判明しました。また、シンプルなサイン波（正弦波）を使用していたため倍音成分がなく、フィルターを動かしても音色の変化を実感しにくいという表現力不足の問題もありました。
* **解決方法（身体感覚に沿ったマッピングへの刷新とハイパスフィルターの採用）**：
  操作系とシンセサイザーの構造を抜本的に見直しました（[sketch.js:L118-154](file:///Users/watanabekeiyu/Desktop/Handy-Synth/sketch.js#L118-154)）：
  1. ピアノや木琴などの鍵盤楽器と同様に、直感的に音高を狙いやすい「手の横位置 $x$ で基本周波数（音高）」をコントロールするマッピングに変更し、手の縦位置 $y$ をピッチベンドに割り当てました。
  2. 音源の波形を、倍音が極めて豊かな「鋸歯状波（sawtooth）」に変更。
  3. 指の開閉（親指と小指の距離 $d$）を「ハイパスフィルター（ローカット）」にマッピング。手を握ると低音が削ぎ落とされたキンキンとした細い音になり、手を開くと低域がしっかりと鳴り響く太い音になるインタラクションを構築しました。
* **結果**：
  音楽の専門知識がない子どもでも、直感的に狙った音程を鳴らしつつ、手の開閉だけでエフェクティブな音色のうねりを作れる豊かな演奏体験（身体性）を提供できました。

## 4. 技術情報
* **フロントエンド**：HTML5, CSS3, JavaScript
* **画像認識エンジン**：ml5.js (Handposeモデル)
* **音響・音声制御**：Web Audio API
* **実装方法・アーキテクチャ**：
  * Webカメラから取得したビデオストリームを `ml5.js` にて毎フレーム解析。
  * 手の開き具合（親指と小指の距離）や、画面内でのXY座標をリアルタイムに抽出。
  * 抽出した座標データや距離を、`Web Audio API` のオシレーター（発振器）の周波数（音高）や、フィルターのカットオフ周波数へリアルタイムにマッピングして同期。

## 厳密な仕様

- **入力**:
  - ユーザーのウェブカメラ映像（WebRTC getUserMedia を通じて取得）。
  - ユーザーによる「Start Audio」ボタンのクリック（ブラウザのオーディオ再生ポリシーに従う）。

- **出力**:
  - ブラウザ上のキャンバスにカメラ映像と検出された手のランドマークを描画。
  - 単一の鋸歯状波（sawtooth）オシレータとハイパスフィルタ（Web Audio API）による音声出力（モノラル）。

- **動作**:
  - ml5.js の Handpose（TensorFlow.js ベース）を使用して手の 21 点ランドマークを検出する。
  - 手の全ランドマークの重心 $x, y$ 座標（動画座標系）および、親指先（landmark index 4）と小指先（index 20）の 2 点間距離 $d$ を計算する。
  - **音高（周波数）の決定**：手の重心の横位置 $x$ （左右反転による操作違和感を防ぐためのミラー補正を適用）に基づき、低周波数 `LOW_FREQ` から高周波数 `HIGH_FREQ` の間で基本周波数を決定する（右に行くほど高い音）。
  - **ピッチベンド**：手の重心の縦位置 $y$ に基づき、上下の動きで微小なピッチ変動（`BEND_RANGE` の範囲）を適用する。
  - **フィルター制御（音色の変化）**：距離 $d$ を事前定義された最小・最大距離範囲 `[MIN_D, MAX_D]` にクランプし、ハイパスフィルターのカットオフ周波数にマッピングする。手を閉じる（$d$ が小さい）ほどカットオフ周波数が高くなり（低音がカットされて細く尖った音になる）、手を開く（$d$ が大きい）ほどカットオフ周波数が低くなり（低音まで響く豊かな音になる）。
  - **Resonance（Q値）調整**：画面上のスライダーを使って、フィルターの共鳴の強さ（Q値）をリアルタイムに変更できる。
  - 周波数やフィルターのパラメータは AudioContext のスムーズなスケジュール（linearRampToValueAtTime）で更新されるため、連続的で滑らかな音響変化が得られる。
  - 手が検出されない場合はゲインをフェードアウトして無音状態にする。

## ファイル一覧

- `index.html`
  - ページのエントリポイント。外部ライブラリ（p5.js, ml5.js）を読み込み、アプリモジュール
    (`config.js`, `audioEngine.js`, `handposeModel.js`, `drawUtils.js`, `sketch.js`) を順に読み込みます。
  - 画面上に「Start Audio」ボタンと「Stop Audio」ボタンを配置し、音声の開始・停止を制御します。また、フィルターのResonance (Q値) を調整するスライダーを配置しています。

- `sketch.js`
  - p5.js のセットアップとメインループを管理する“司令塔”。
  - カメラキャプチャの生成、キャンバスのリサイズ処理、handpose の予測結果受け取り（コールバック）を行います。
  - 受け取ったランドマークから距離・重心などを計算し、`audioEngine` と `drawUtils` にデータを渡して描画・音声制御を行います。

- `config.js`
  - アプリ全体で使う定数（MIN_D / MAX_D / LOW_FREQ / HIGH_FREQ / BEND_RANGE / フィルターのカットオフ範囲やQ値 / グラフ設定など）を一元管理し、`window.CONFIG` として公開します。

- `audioEngine.js`
  - Web Audio API を使った鋸歯状波（sawtooth）シンセとハイパスフィルターの管理（オシレータ生成、ハイパスフィルター適用、Gain 管理、パラメータのスムーズな更新、開始・停止、フェードイン/フェードアウト、Q値変更）を行います。
  - `window.audioEngine` として API（ensureStarted, rampToFrequency, setHighpassCutoff, setFilterQ, noteOn, noteOff, startAudio, stopAudio など）を提供します。

- `handposeModel.js`
  - ml5.handpose の初期化と予測イベントの登録を行うラッパーです。
  - `window.handposeCtrl.init(video, onPredict)` でモデルを初期化し、予測コールバックを登録します。

- `drawUtils.js`
  - 手のランドマーク描画（キーポイント＋接続線）、周波数の推移グラフ、およびハイパスフィルターのカットオフ周波数特性グラフの描画ロジックを切り出したユーティリティ群。
  - p5 の描画関数内から `window.drawUtils.drawHand(...)` / `drawFrequencyGraph(...)` / `drawFilterGraph(...)` を呼んで使います。

- `README.md`
  - このファイル。プロジェクトの目的、実行手順、パラメータや注意点を記載しています。

## 必要条件（実行環境）

- ブラウザ：最新の Chrome、Firefox、Edge、あるいは Safari のいずれか（WebRTC と Web Audio API をサポートしていること）。
  - 注意: 一部ブラウザや古いバージョンでは期待通りに動作しない場合があります。
- ローカルでの実行は HTTP サーバを使用してください（`file://` で直接開くとカメラやオーディオの権限・ワークレットの制限で正しく動作しないことがあります）。
- ネットワーク接続：ml5.js は CDN から読み込まれるため、初回読み込み時にインターネット接続が必要です。

## 実行手順（正確）

1. ターミナルを開き、プロジェクトのルートディレクトリに移動します。例:

```bash
cd /Users/watanabekeiyu/Desktop/Handy-Synth
```

2. 簡易 HTTP サーバを起動します（Python 3 を想定）:

```bash
python3 -m http.server 8000
```

3. ブラウザで次の URL を開きます:

```
http://localhost:8000
```

4. ページが表示されたら、必ず最初に「Start Audio」ボタンをクリックします。
   - これによりブラウザの AudioContext が `resume()` され、オシレータの音が出せるようになります。
   - ブラウザがカメラ使用の許可を求めるので「許可」してください。

5. カメラ映像がキャンバスに表示され、手が検出されると緑のランドマークが表示されます。手を左右に動かすと音の高さ（周波数）が変わり、上下に動かすと微小なピッチベンドがかかります。また、親指と小指を開閉することでハイパスフィルターのカットオフ周波数が変化し、音の太さをコントロールできます。

## 主要パラメータ（`config.js` / `sketch.js` 内の変数）

- **MIN_D** (数値): 判定に使用する指間距離の下限。デフォルト: 20
- **MAX_D** (数値): 判定に使用する指間距離の上限。デフォルト: 300
- **LOW_FREQ** (Hz): 手が最も左にあるときに対応する基本周波数。デフォルト: 150
- **HIGH_FREQ** (Hz): 手が最も右にあるときに対応する基本周波数。デフォルト: 900
- **BEND_RANGE** (比率): 手の縦位置によるピッチ変動の上限（±比率）。デフォルト: 0.06（±6%）
- **FILTER_MIN_CUTOFF** (Hz): ハイパスフィルターの最低カットオフ周波数（指を完全に開いたとき）。デフォルト: 200
- **FILTER_MAX_CUTOFF** (Hz): ハイパスフィルターの最高カットオフ周波数（指を完全に閉じたとき）。デフォルト: 5000
- **FILTER_Q** (数値): ハイパスフィルターの初期Q値（共鳴度）。デフォルト: 0.9
- **gain の目標値**: 手が検出されたときの最大ボリューム（`audioEngine.noteOn` のデフォルト引数等で設定）。

これらの値は `config.js` 内で直接変更できます。視覚的な位置や手のサイズ、カメラとの距離によって最適値が変わるため、実機で確認しながら調整してください。

## 安全で確実な動作のための注意点（トラブルシューティング）

- 音が鳴らない／Start ボタンを押しても無反応:
  - ブラウザのコンソールにエラーが出ていないか確認してください。
  - `http://localhost:8000` のように HTTP サーバ経由で開いているか確認（`file://` ではないこと）。
  - ブラウザがカメラのアクセスをブロックしていないか確認。

- コンソールに "Unable to load a worklet's module" などのエラーが出る場合:
  - 以前の実装で `p5.sound` を使っていると発生する可能性があります。本プロジェクトはネイティブ WebAudio を使用しているため、`p5.sound` の読み込みが無いことを確認してください。

- 手が検出されない／ランドマークがずれる:
  - 照明を明るくする、背景をシンプルにする、カメラに手を近づける／遠ざけるなどで改善します。
  - `MIN_D` と `MAX_D` を調整して、指距離のスケールをカメラ距離に合わせてください。
